# Ask the docs: a minimal RAG app

A Next.js page sends a question to a FastAPI server, which finds relevant text in
local files (BM25) and passes it to an LLM. The LLM is a built-in stub by
default, so no API key is needed. An OpenAI-compatible endpoint is optional.

```
Browser -> Next.js /api/ask -> FastAPI /ask -> BM25 retrieval -> stub or proxy
```

See [SPEC.md](SPEC.md) for the full specification.

## Requirements

- Node.js 26.13.1 (see `.nvmrc`) with npm 11.20.0
- Python 3.14.4 with `venv`

## Setup

From the project root:

```bash
nvm use
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
npm ci --prefix frontend
```

## Run

Use two terminals, both in the project root.

Terminal 1, the backend on port 8000:

```bash
backend/.venv/bin/python -m uvicorn app.main:create_app --factory \
  --app-dir backend --host 127.0.0.1 --port 8000
```

Terminal 2, the frontend:

```bash
npm --prefix frontend run dev
```

Open the address that Next.js prints (normally <http://localhost:3000>) and ask,
for example, "Which planet is the largest?". The answer starts with `[stub]` and
lists its sources. A question about something else, such as "Who invented the
telephone?", shows a fallback answer and "No matching sources."

If port 8000 is taken, start the backend on another port and start the frontend
with `BACKEND_URL` set to that address. To move the frontend, add
`-- --port <port>` to the `npm` command.

### Documents

The backend reads the `*.md` and `*.txt` files directly inside `data/` (or
`DOCS_DIR`) once, at startup. Restart it after changing them. Matching is by
exact words: there is no stemming and no synonym handling, so "planet" does not
match "planets".

## Environment variables

All are optional unless noted. `.env.example` lists the names.

| Name | Read by | Purpose |
|---|---|---|
| `DOCS_DIR` | backend | Documents folder (default: `data/`) |
| `LLM_PROXY_URL` | backend | Enables proxy mode; API base address, including any version path |
| `LLM_PROXY_API_KEY` | backend | Bearer key, sent only when set |
| `LLM_PROXY_MODEL` | backend | Model name; **required** in proxy mode |
| `BACKEND_URL` | frontend server | FastAPI base address (default: port 8000 on `127.0.0.1`) |
| `NEXT_TELEMETRY_DISABLED` | Next.js | Turns off telemetry; `test.sh` sets it |

The backend does **not** load `.env` files: export the variables in the terminal
that starts it. Next.js does load `.env*` files placed in `frontend/`. Never
commit secrets.

To use a real LLM, set `LLM_PROXY_URL` and `LLM_PROXY_MODEL` (and
`LLM_PROXY_API_KEY` if the endpoint needs one) before starting the backend. The
retrieved text and the question are sent to that endpoint. If you do not see an
answer from it, check that the question matches the documents: with no matching
text the LLM is not called.

## API

| Endpoint | Behavior |
|---|---|
| `GET /health` | `{"status": "ok", "chunks": <count>}` |
| `POST /ask` | `{"question": "..."}` (1 to 1000 characters after trimming) returns `{"answer", "sources": [{"file", "text", "score"}], "mode"}`; 422 for a bad question, 502 if the LLM request fails |

## Test

```bash
./test.sh
```

It installs missing or outdated dependencies, then runs the backend unit tests,
the frontend unit tests, a production build and the end-to-end tests, stopping at
the first failure. Only the first-time setup needs network access. The tests use
mocks and fixtures, connect only to `127.0.0.1` on free ports and stop the
servers they start.

A `StarletteDeprecationWarning` suggesting `httpx2` is expected.

The end-to-end tests use the existing frontend build. To run them alone:

```bash
npm --prefix frontend run build
backend/.venv/bin/python -m pytest e2e
```

Not covered automatically: clicking through the page in a real browser, and a
real LLM endpoint (proxy mode is tested against a mock only).

## Choices made while building

Points the specification left open:

- `.env.example` is added (names only); `.gitignore` ignores `.env*` except it.
- An empty `DOCS_DIR` or `BACKEND_URL` counts as unset.
- A UTF-8 byte order mark at the start of a document is dropped.
- FastAPI's automatic `/docs`, `/redoc` and `/openapi.json` pages are turned off,
  leaving only the two endpoints above.
- A trailing slash on `BACKEND_URL` is ignored.
- The page sends the question already trimmed.
- Basic styling lives in `frontend/app/globals.css`.
- `next.config.ts` sets the Turbopack root to `frontend/`, and sets
  `agentRules: false` so that `next dev` does not write an `AGENTS.md` file.
- `next-env.d.ts` is generated by Next.js and is not committed.
