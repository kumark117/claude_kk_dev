# Ask the docs: a minimal RAG app

A Next.js page sends a question to a FastAPI server. The server finds relevant
text in local files (BM25, keyword matching) and passes it to an LLM: a built-in
stub by default, or an OpenAI-compatible endpoint. The full design is in
[SPEC.md](SPEC.md).

```
Browser → Next.js /api/ask → FastAPI /ask → BM25 retrieval → stub or LLM proxy
```

## Requirements

- Node.js 26.13.1 and npm 11.20.0 (`.nvmrc` is provided for nvm)
- Python 3.14 with `venv`

## Setup

Run all commands from this directory.

```bash
nvm use                      # or: nvm install
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
npm ci --prefix frontend
```

## Run

No API key or environment variable is needed.

Terminal 1, the backend on port 8000:

```bash
backend/.venv/bin/python -m uvicorn app.main:create_app --factory \
  --app-dir backend --host 127.0.0.1 --port 8000
```

Terminal 2, the frontend:

```bash
npm --prefix frontend run dev
```

Open the address that Next.js prints (normally <http://localhost:3000>) and ask,
for example, "Why does my coffee taste bitter?". You get a `[stub]` answer and
the matching sources. An unrelated question shows a fallback answer and "No
matching sources."

If port 8000 is taken, give the backend another port and start the frontend with
`BACKEND_URL=http://127.0.0.1:<port>`. Next.js picks another port by itself if
3000 is taken (or pass `-- --port <port>`).

For a production build, use `npm --prefix frontend run build` followed by
`npm --prefix frontend start`.

The API can also be called directly:

```bash
curl http://127.0.0.1:8000/health
curl -H 'content-type: application/json' \
  -d '{"question": "How do I water houseplants?"}' http://127.0.0.1:8000/ask
```

## Environment variables

The names are listed in [.env.example](.env.example).

| Name | Used by | Purpose |
|---|---|---|
| `DOCS_DIR` | backend | Documents folder (default: `data/`) |
| `LLM_PROXY_URL` | backend | Enables proxy mode; API base address, including any version path |
| `LLM_PROXY_API_KEY` | backend | Optional bearer key |
| `LLM_PROXY_MODEL` | backend | Model name; required in proxy mode |
| `BACKEND_URL` | frontend server | FastAPI base address (default: port 8000 on `127.0.0.1`) |
| `NEXT_TELEMETRY_DISABLED` | `test.sh` | Turns off Next.js telemetry |

The backend does **not** load `.env` files: export the variables in the shell
that starts it. (Next.js itself reads `frontend/.env.local` if you create one.)
Never commit real keys.

To use a real model, set `LLM_PROXY_URL` and `LLM_PROXY_MODEL` (and
`LLM_PROXY_API_KEY` if the endpoint needs it) before starting the backend. The
question and the retrieved text are then sent to that endpoint.

## Documents

`*.md` and `*.txt` files directly inside the documents folder are read once, at
startup. Restart the backend after changing them. Retrieval matches words, not
synonyms or word forms ("plant" does not match "plants").

## Test

```bash
./test.sh
```

It installs dependencies when they are missing or the pinned files have changed,
then runs the backend tests, the frontend tests, the frontend build and the
end-to-end tests. It needs the network only for installation. No test uses a
real LLM; the end-to-end tests start real servers on free loopback ports, with a
mock LLM, and stop them afterwards.

To run one part after setup:

```bash
backend/.venv/bin/python -m pytest backend/tests
npm --prefix frontend test
npm --prefix frontend run build && backend/.venv/bin/python -m pytest e2e
```

A `StarletteDeprecationWarning` mentioning `httpx2` is expected.

## Choices made during the build

Where SPEC.md left something open:

- The browser sends the question already trimmed.
- A successful reply that is not in the expected shape shows
  `Request failed (<status>)`.
- A trailing slash on `BACKEND_URL` is ignored. An empty `BACKEND_URL` or
  `DOCS_DIR` counts as unset.
- `test.sh` stops if the Node.js version differs from `.nvmrc` and nvm cannot
  select it.
- `frontend/next-env.d.ts` is generated by Next.js and therefore ignored by git.
- `.gitignore` excludes `.env*` but keeps `.env.example`.
- Styling is a small inline stylesheet in `app/layout.tsx`.
- The Turbopack root is pinned to `frontend/`, and `agentRules` is off so that
  `next dev` does not write an `AGENTS.md` file.
