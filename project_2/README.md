# Ask the docs: a minimal RAG app

A Next.js page sends a question to a FastAPI server. The server picks the most
relevant text from local files (BM25) and passes it to an LLM: a built-in stub by
default, or an OpenAI-compatible endpoint. See [SPEC.md](SPEC.md) for the full
behaviour.

```
Browser -> Next.js /api/ask -> FastAPI /ask -> BM25 over data/ -> stub or LLM proxy
```

## Requirements

- Node.js 26.13.1 (see `.nvmrc`) with npm 11
- Python 3.14 with `venv`

## Setup

From the project root:

```bash
nvm use
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
npm ci --prefix frontend
```

## Run

Terminal 1, the backend on port 8000 (from the project root):

```bash
backend/.venv/bin/python -m uvicorn --factory app.main:create_app --app-dir backend --host 127.0.0.1 --port 8000
```

Terminal 2, the frontend:

```bash
nvm use
npm --prefix frontend run dev
```

Open the address that Next.js prints (usually http://localhost:3000) and ask, for
example, "Why does Mars look red?". With no variables set you get a `[stub]`
answer and its sources.

For a production build, run `npm --prefix frontend run build` and then
`npm --prefix frontend start`.

If port 8000 or 3000 is taken, choose others:

```bash
# terminal 1: use --port <backend port> in the uvicorn command above
# terminal 2:
BACKEND_URL=http://127.0.0.1:<backend port> npm --prefix frontend run dev -- --port <ui port>
```

## Environment variables

All are optional unless noted. `.env.example` lists the names. The backend does
**not** load `.env` files, so export the variables in the shell that starts it.
Never commit secrets.

| Name | Used by | Purpose |
|---|---|---|
| `DOCS_DIR` | backend | Documents folder (default: `data/`) |
| `LLM_PROXY_URL` | backend | Enables proxy mode; API base address, including any version path |
| `LLM_PROXY_API_KEY` | backend | Bearer key, sent only when set |
| `LLM_PROXY_MODEL` | backend | Model name; required in proxy mode |
| `BACKEND_URL` | frontend server | FastAPI base address (default: port 8000 on `127.0.0.1`) |
| `NEXT_TELEMETRY_DISABLED` | `test.sh` | Turns off Next.js telemetry |

In proxy mode the backend posts to `<LLM_PROXY_URL>/chat/completions`, sending the
question and the retrieved text to that endpoint.

## Documents

The backend reads the `*.md` and `*.txt` files directly inside the documents
folder once, at startup. Restart it after changing them. Retrieval matches words,
not meanings: no synonyms and no stemming ("planet" does not match "planets").

## API

| Endpoint | Behaviour |
|---|---|
| `GET /health` | `{"status": "ok", "chunks": <count>}` |
| `POST /ask` with `{"question": "..."}` (1 to 1000 characters) | `{"answer", "sources": [{"file", "text", "score"}], "mode"}`; 422 for an invalid question, 502 if the LLM request fails |

## Test

```bash
./test.sh
```

It installs dependencies when they are missing or their pinned files have changed
(this step may need the network), then runs the backend tests, the frontend tests,
the frontend build and the end-to-end tests. It stops at the first failure. Once
installed it runs offline: tests use mocks, fixtures and loopback connections on
free ports, never a real LLM.

Importing FastAPI's `TestClient` prints a `StarletteDeprecationWarning` about
`httpx2`. This is expected.

The end-to-end tests check the server path over HTTP; they do not drive a
browser. To run them alone, build the frontend first:

```bash
npm --prefix frontend run build
backend/.venv/bin/python -m pytest e2e
```

## Choices made while building

Details that SPEC.md leaves open:

- An empty `DOCS_DIR` or `BACKEND_URL` counts as unset.
- One trailing slash on `BACKEND_URL` is ignored.
- The route handler forwards the request body unchanged once it parses as JSON.
- The page also puts an "Answer" heading above the answer.
- `next.config.ts` pins the Turbopack root to `frontend/` and sets
  `agentRules: false`, so `next dev` does not write extra files into the project.
- `next-env.d.ts` is generated by Next.js and is git-ignored.
- Styling is a few inline styles.
