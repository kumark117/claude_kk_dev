# Minimal RAG

A Next.js page sends a question to a FastAPI server. The server retrieves
relevant text from local files (BM25) and passes it to an LLM: a built-in stub
by default, or an optional OpenAI-compatible proxy. [SPEC.md](SPEC.md) is the
full specification.

## Requirements

- Node.js 26.13.1 (see `.nvmrc`; with nvm: `nvm install && nvm use`)
- npm 11.20.0
- Python 3.14.4 with `venv`

## Setup

From the project root:

```bash
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
npm ci --prefix frontend
```

`./test.sh` also does this when needed.

## Run

Use two terminals, both starting at the project root.

Terminal 1, the backend on port 8000:

```bash
backend/.venv/bin/python -m uvicorn app.main:create_app --factory \
  --app-dir backend --host 127.0.0.1 --port 8000
```

Terminal 2, the frontend:

```bash
npm --prefix frontend run dev
```

Open the address that Next.js prints (usually <http://localhost:3000>) and ask
something about the sample documents, for example "How is espresso brewed?".
With no variables set, the answer starts with `[stub]` and lists its sources.

If port 8000 is taken, pick another one for the backend and start the frontend
with `BACKEND_URL=http://127.0.0.1:<port>`. To choose the frontend port, add
`-- --port <port>` to the `dev` command.

For a production build, use `npm --prefix frontend run build` followed by
`npm --prefix frontend run start`.

## Documents

The backend reads the `*.md` and `*.txt` files directly inside `data/` (or
`DOCS_DIR`) as UTF-8, once, at startup. Restart it after changing them.
Retrieval matches words, not synonyms, and does no stemming ("planet" does not
match "planets").

## Environment variables

| Name | Used by | Purpose |
|---|---|---|
| `DOCS_DIR` | backend | Documents folder (default: `data/`) |
| `LLM_PROXY_URL` | backend | Enables proxy mode; API base address, including any version path |
| `LLM_PROXY_API_KEY` | backend | Optional bearer key |
| `LLM_PROXY_MODEL` | backend | Model name; required in proxy mode |
| `BACKEND_URL` | frontend server | FastAPI base address (default: port 8000 on `127.0.0.1`) |
| `NEXT_TELEMETRY_DISABLED` | `test.sh` | Turns off Next.js telemetry |

Set them in the shell that starts the server. The backend does not load `.env`
files. `.env.example` lists the names; if you copy it to `.env`, load it with
`set -a; source .env; set +a`. Never commit secrets.

To use a proxy, set `LLM_PROXY_URL`, `LLM_PROXY_MODEL` and, if the server needs
one, `LLM_PROXY_API_KEY`, then start the backend. The question and the retrieved
text are sent to that server.

## Test

```bash
./test.sh
```

It installs dependencies when they are missing or the pinned files change, then
runs, stopping at the first failure:

1. backend unit tests (`pytest backend/tests`)
2. frontend unit tests (Vitest)
3. the Next.js production build
4. end-to-end tests (`pytest e2e`): real Uvicorn and `next start` processes on
   free loopback ports, with a mock LLM server

Only the first-time setup needs network access. No test uses an API key or a
real LLM. A `StarletteDeprecationWarning` that suggests `httpx2` is expected.

## Choices made while building

Where the specification left a detail open:

- A UTF-8 byte order mark is ignored, so it cannot hide a first heading.
- An empty `DOCS_DIR` or `BACKEND_URL` counts as unset.
- "Thinking…" appears as a status line under the form.
- `next-env.d.ts` is generated by Next.js, so it is not tracked.
- `next.config.ts` sets the Turbopack root to `frontend/` and stops `next dev`
  from generating `AGENTS.md`.
