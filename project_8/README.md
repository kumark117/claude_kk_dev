# Minimal RAG

Ask a question in the browser and see an answer with the sources behind it. A
Next.js page calls a FastAPI server, which finds relevant text in local files
(BM25) and passes it to an LLM. The LLM is a built-in stub by default, with an
optional OpenAI-compatible proxy. No API key is needed.

[SPEC.md](SPEC.md) is the full specification.

## Requirements

- Node.js 26.13.1 (see `.nvmrc`; `nvm install` picks it up) with npm 11.20.0
- Python 3.14.4 with `venv`

## Setup

Run these from the project root:

```
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
npm ci --prefix frontend
```

## Run

Terminal 1, the backend on port 8000:

```
backend/.venv/bin/python -m uvicorn app.main:create_app --factory --app-dir backend --host 127.0.0.1 --port 8000
```

Terminal 2, the frontend:

```
npm --prefix frontend run dev
```

Open the address that Next.js prints (normally <http://localhost:3000>) and try
"Why is Mars called the red planet?". In stub mode the answer starts with
`[stub]` and the sources are listed below it. An unrelated question shows a
fallback answer and "No matching sources."

If port 8000 is taken, start the backend on another port and point the frontend
at it:

```
BACKEND_URL=http://127.0.0.1:<port> npm --prefix frontend run dev
```

Another frontend port can be chosen with
`npm --prefix frontend run dev -- --port <port>`.

For a production build, use `npm --prefix frontend run build` and then
`npm --prefix frontend start`.

## Documents

The backend reads the `*.md` and `*.txt` files directly inside `data/` (or
`DOCS_DIR`). They are read once at startup, so restart the backend after editing
them. Files must be UTF-8. Search matches words only: no stemming or synonyms.

## Environment variables

All are optional in stub mode.

| Name | Used by | Purpose |
|---|---|---|
| `DOCS_DIR` | backend | Documents folder (default `data/`) |
| `LLM_PROXY_URL` | backend | Enables proxy mode; API base address, including any version path |
| `LLM_PROXY_API_KEY` | backend | Optional bearer key |
| `LLM_PROXY_MODEL` | backend | Model name; required in proxy mode |
| `BACKEND_URL` | frontend server | FastAPI base address (default port 8000 on `127.0.0.1`) |
| `NEXT_TELEMETRY_DISABLED` | `test.sh` | Turns off Next.js telemetry |

Set the backend variables in the shell that starts it. The backend does not load
`.env` files; `.env.example` only lists the names. Never commit secrets.

In proxy mode the backend sends the question and the retrieved text to
`<LLM_PROXY_URL>/chat/completions`.

## API

| Endpoint | Result |
|---|---|
| `GET /health` | `{"status": "ok", "chunks": <count>}` |
| `POST /ask` with `{"question": "..."}` | `{"answer", "sources": [{"file", "text", "score"}], "mode"}` |

A question must be 1 to 1000 characters after trimming (otherwise 422). A failed
LLM call returns 502.

## Test

```
./test.sh
```

This installs dependencies when they are missing or their pinned files changed,
then runs the backend tests, the frontend tests, the frontend build and the
end-to-end tests. Only the first-time install needs the network. Tests use mocks
and fixtures, connect only to `127.0.0.1`, and pick free ports.

A `StarletteDeprecationWarning` about `httpx2` is expected.

The end-to-end tests do not drive a browser; UI behaviour is covered by the
component tests.

## Choices made during the build

- `.env.example` was added to list the variable names; `.gitignore` ignores all
  other `.env*` files.
- `next-env.d.ts` and `*.tsbuildinfo` are generated by the build and ignored.
- An empty `DOCS_DIR` or `BACKEND_URL` is treated as unset.
- The page sends the question already trimmed.
- A successful reply that the page cannot read as JSON shows
  `Request failed (<status>)`.
- The 30-second LLM timeout is applied by `httpx` to each network operation
  (connect, read, write), not to the request as a whole.
- `test.sh` stops if the exact Node.js version cannot be selected.
- `agentRules: false` in `next.config.ts` stops `next dev` from writing an
  `AGENTS.md` file into the project.
